## 带宽怎么选：最容易被低估的一项

带宽决定了访客打开页面的速度，也直接决定月账单，个人网站 1Mbps 起步是教程里给出的参考值。

公网带宽有两种常见计法。按固定带宽，是买死一个带宽值按月付费，流量暴涨也不另收钱；按使用流量，是给一个较高的峰值、按实际产生的流量计费。前者适合流量平稳的官网，后者适合平时没人来、活动日突然爆量的站点。

## 下单前必须确认的三件事

配置选完不等于万事大吉，备案、端口、备份这三件事，漏了任何一件都会在上线后折腾你。

第一件是**备案**。用域名对外提供服务、服务器又选在中国大陆地域，就必须先完成 ICP 备案，未备案的域名是访问不了的。不想走备案流程，可以把地域选在中国香港或海外。备案需要时间，别等服务器买好了才开始办。

第二件是**端口**。网站上线流程里，“开通端口号”是独立的一步：Web 服务常用的 80、443 端口要在安全组里放行。本机测试一切正常、外网访问却一直超时，问题多半出在这里。

第三件是**备份**。ECS 支持快照备份和镜像备份，数据出问题可以恢复。上线前就设好自动快照策略，比事后补救省心得多。

## 买完之后：从远程连接到网站上线

服务器到手后的完整流程是：远程连接 → 搭 Web 环境 → 部署程序 → 域名解析。Linux 和 Windows 两条路都有现成工具。

1. **远程连接**：进控制台，打开“云服务器 ECS”下的实例列表，点实例右侧的“远程连接”，输入管理终端密码即可进入服务器。
2. **搭环境**：Windows 系统自带 IIS（Internet 信息服务管理器），打开后选择“添加网站”，填好网站名称和物理路径，绑定里把主机名写成你的域名，再到“默认文档”里加上首页文件名，这样访客只输域名、不带具体页面地址时，也能自动落到首页。Linux 用户更省事，👉 [用宝塔面板镜像开通一台轻量服务器](https://www.aliyun.com/product/swas?userCode=5eqf8rny)，可视化面板把建站、数据库、证书一起管了。
3. **部署程序**：WordPress 这类现成程序有预装镜像，装好就是完整网站，不用从零写代码。
4. **域名解析**：把域名解析到服务器公网 IP，等备案通过，网站就能正常访问了。
